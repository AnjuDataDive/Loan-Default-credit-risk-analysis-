Dashboard 1: Credit Risk & Default Analysis

Project Overview

This Power BI dashboard analyzes loan applications and historical default patterns to understand how customer income, credit scores, employment history, and loan types relate to loan defaults.

The dashboard provides a consolidated view of loan application volume, total loan amount, and default trends to help stakeholders identify customer segments that may require closer credit risk monitoring.

Business Objective

To analyze historical loan defaults across different customer and loan segments, identify patterns associated with higher default rates, and support data-informed credit risk assessment.

Key Performance Indicators (KPIs)

The dashboard highlights four key metrics:

- Total Applications: Approximately 2,000 loan applications.
- Total Loan Amount: 2 billion, as displayed in the dashboard.
- Total Defaults: 137 defaulted applications.
- Historical Default Rate: 9.13%.

Note: The displayed figures reflect the dashboard at the time of the screenshot and may change when filters are applied.

Key Analysis & Visualizations

1. Default Rate by Income Bracket

Compares historical loan default rates across customer income groups to examine how defaults vary by income level.

2. Default Rate by Employment History

Shows how historical default rates differ across employment experience groups, helping explore the relationship between employment stability and loan repayment outcomes.

3. Default Rate by Credit Score Band

Breaks down defaulted applications by credit score category to examine how credit profiles are represented among default cases.

4. Default Rate by Loan Type

Compares historical default rates across Personal, Auto, Home, Business, and Education loans to identify loan categories that may need closer monitoring.

Interactive Filters

Users can filter the dashboard using:

- State: Explore loan default patterns across locations.
- Loan Type: Focus on specific loan categories.
- Application Date: Analyze applications over different periods.

These filters help users explore specific segments instead of relying only on overall figures.

Tools & Technologies

- Power BI – Dashboard development and data visualization
- DAX – KPI calculations and analytical measures
- CSV datasets – Customer and loan application data

Business Value

This dashboard helps stakeholders:

- Monitor overall loan application and default trends.
- Compare historical defaults across income, credit score, employment, and loan categories.
- Identify customer segments that may deserve further investigation.
- Support credit risk monitoring using historical data.

Important Note

This project uses sample data for portfolio and analytical purposes. Historical default rates describe observed outcomes in the dataset; they do not represent a validated prediction of future defaults or an official lending policy.
