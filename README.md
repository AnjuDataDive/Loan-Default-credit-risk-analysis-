BFSI Loan Default Risk & Credit Review Analysis

Project Overview

This project focuses on analyzing loan default risk and supporting credit review decisions in the Banking, Financial Services, and Insurance (BFSI) sector using Power BI.

The objective is to understand which customer segments have a higher likelihood of loan default and identify loan applications that may require manual review before a credit decision is made.

The dashboards transform loan application data into meaningful insights that can help credit teams assess risk, understand customer segments, and prioritize applications for further evaluation.

Business Objectives

- Analyze loan default risk across different customer segments.
- Understand how income levels, loan types, employment history, and geography relate to default risk.
- Identify applications that may require manual credit review.
- Differentiate between standard review and manual review recommendations.
- Support data-driven credit assessment and risk monitoring.

Tools & Technologies

- Power BI – Dashboard development and data visualization
- DAX – Measures and calculated fields
- Power Query – Data cleaning and transformation
- CSV – Data storage and input

Project Dashboards

Objective: Understand loan default risk across different customer segments.

2. Credit Review Recommendation

Objective: Identify loan applications that may require additional credit assessment.

This dashboard focuses on classifying applications into Manual Review and Standard Review categories based on the project's defined review criteria.

It helps prioritize applications that may need further investigation while distinguishing them from applications that can proceed through the standard review process.

Key Business Questions

1. Which customer income segments have higher loan default risk?
2. How does default risk vary across loan types?
3. What patterns can be observed across employment history and geography?
4. Which loan applications should be prioritized for manual review?
5. How can data visualization support a more structured credit review process?

Key Takeaways

- Segment-level analysis helps highlight differences in loan default risk.
- Comparing loan types, income brackets, employment history, and geography can reveal useful risk patterns.
- A structured review classification can help credit teams prioritize applications for further assessment.
- Power BI makes loan risk indicators easier to monitor and communicate.

Disclaimer

This is a portfolio project created for analytical and educational purposes. The findings depend on the dataset and the assumptions used in the analysis. The review categories are analytical recommendations and should not be treated as final lending decisions.

Conclusion

This project demonstrates the application of Power BI to loan risk analysis and credit review prioritization. It combines customer segmentation, risk indicators, and review recommendations to illustrate how data analytics can support decision-making in the BFSI domain.
